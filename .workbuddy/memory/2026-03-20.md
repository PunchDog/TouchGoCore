### 使用示例对比

**旧版本（已移除）：**
```go
condition := &db.Condition{}
condition.SetTableName("users").
    SetFilter("status", "active").
    Order("created_at DESC").
    Limit(10)
mysqlDB.SetCondition(condition)
result, _ := mysqlDB.Query()
rows := result.GetAll()
for rows.Next() {
    name := rows.GetString("name")
    age := rows.GetInt("age")
}
```

**新版本（GORM）：**
```go
var users []User
mysqlDB.Where("status = ?", "active").
    Order("created_at DESC").
    Limit(10).
    Find(&users)
for _, user := range users {
    fmt.Println(user.Name, user.Age)
}
```
